# 充电站平面布置案例：双排斜列19台320kW直流桩+S304出入口

1. 方案摘要
项目：充电站平面布置图（图号 002），接 S304 省道。布置模式：双排斜列（鱼骨），中间内部道路。直流桩 19 台 320kW（直流充电桩1～19），交流桩 0 台。箱变以终端型为主：新建1#～4# 终端型箱变 1250kVA，新建5# 终端型箱变 1000kVA；另有环网柜 HW。检索关键词：充电站、斜列、鱼骨、直流充电桩、320kW、19桩、1250kVA、1000kVA、终端型箱变、环网柜、内部道路 8m、电缆沟 1200x1100、S304、大门、厂房、车棚拆除。

2. 规模配置
- 内部道路约 8000mm（8m）宽，位于两排布位之间，作为主要车行通道
- 直流充电桩 19 台，功率 320kW，编号连续：直流充电桩1 至 直流充电桩19
- 下排（近大门/南侧一带）约 直流充电桩1～12；上排约 直流充电桩13～19
- 交流充电桩：本图未布置 14kW 交流桩（图例有空心方块，本方案不用）
- 箱变：新建1#、2#、3#、4# 终端型箱变各 1250kVA；新建5# 终端型箱变 1000kVA；环网柜 HW 与箱变成组布置
- 电缆沟截面 1200(W)×1100(H)，沿内部道路/桩位带敷设
- 出入口：大门朝向 S304 省道一侧（场地西侧一带）
- 间距标注可参考图面 8000、7116、4561 等，生成时通道优先保证约 8m，不必照抄所有毫米数

3. 布置模式
- 车位斜列约 -45°（鱼骨），上下两排夹一条内部道路，不要做成 90° 垂直停车
- 充电桩为实心方块（320kW 直流），位于车位车头；一桩服务相邻车位（常见一桩两位或一位一桩，按编号 1～19 连续布置，不要漏号）
- 上排相对更短（约 13～19），下排更长（约 1～12）
- 箱变与环网柜成组，靠近厂房一侧，不要拆到每个车位旁边
- 电源路径：环网柜/箱变 → 电缆沟 → 至各 320kW 直流桩
- 图例：环网柜 HW、箱式变电站、320kW直流桩、车位、绿化、树木、电缆沟

4. 电气与建构筑物
- 西侧：S304 省道 + 大门
- 东侧：厂房
- 北侧：建筑
- 南侧：车棚（拆除），生成时不要把已拆除车棚画成保留建筑，可用 demolish 或 notes 标明拆除
- 绿化、树木沿边角与道路边缘，不占内部道路和车位
- 特别约束：内部道路约 8m；出入口接省道；箱变成组靠厂房；北向见图中北箭头（大致朝上）

5. 生成时如何复用
用户提到「19 个 320kW 直流桩、双排斜列、内部道路、接省道/大门、箱变靠厂房」时套用：两条 parkingRows（下排 startNo=1 stalls≈12，上排 startNo=13 stalls≈7），angleDeg 约 -45，charger.type=dc_320kw，中间 roads 标注内部道路且宽度约 8m，gate 在西/南侧并 roadLabel=S304省道，trenches widthMm=1200 heightMm=1100，equipment 含多台终端型箱变（默认 4×1250kVA + 1×1000kVA）和环网柜。若用户只要 1 台 1250kVA 或只要 15 桩，只改 stalls 与 equipment，不要照抄 19 桩和五台箱变。车棚拆除、厂房轮廓以当前需求或读图为准。
