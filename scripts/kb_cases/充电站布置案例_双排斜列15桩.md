# 充电站平面布置案例：双排斜列15台320kW直流桩

1. 方案摘要
项目：既有厂区充电站改造。布置模式：双排斜列。直流桩 15 台 320kW，交流桩 0 台，箱变 3 台 1600kVA（2 台环网型 + 1 台终端型）。检索关键词：充电站、斜列、直流充电桩、320kW、1600kVA、环网型箱变、电缆沟 1200x1100。

2. 规模配置
- 场地中等，车位沿内部道路两侧斜列
- 车位 15 个，图面标注约 4m × 17m（含通道方向尺寸，生成 JSON 时 stallWidthM 可用 2.6、stallLengthM 可用 6.0，按实际车位短边/长边理解）
- 直流充电桩 15 台，功率 320kW，编号 直流充电桩1 至 直流充电桩15
- 箱变 3 台，单台 1600kVA：新建1#环网型箱变、新建2#环网型箱变、新建3#终端型箱变
- 电缆沟截面 1200(W)×1100(H)，长度约 95m，位于两排布位之间
- 出入口在场地边缘，北向见图中北箭头

3. 布置模式
- 车位排列：斜列约 -45°，两排，中间内部道路，交通流线有导向箭头
- 充电桩位于各车位车头，实心方块符号为 320kW 直流桩
- 三台箱变集中布置在靠厂房一侧
- 电缆沟连接箱变与各桩位
- 图例：环网柜 HW、箱式变电站、低压配电箱、高压计量箱、隔离开关、避雷器、断路器、320kW直流桩、14kW交流桩、10kV电缆、0.4kV电缆、电缆井、车位、绿化、树木

4. 电气与建构筑物
- 建构筑物：厂房位于箱变一侧
- 10kV 虚线、0.4kV 实线；箱变出线经电缆沟至桩
- 绿化与树木沿场地边角布置

5. 生成时如何复用
用户说「15 个 320kW 直流桩、斜列、箱变」时套用：parkingRows 两排 angleDeg=-45、charger.type=dc_320kw 且 startNo 连续、trenches widthMm=1200 heightMm=1100、legend 含 ring_cabinet/box_transformer/dc_320kw/parking。箱变台数与容量按用户当次需求（本案例为 3×1600kVA，用户若只要 1×1250kVA 则改 equipment，不要照抄三台）。
