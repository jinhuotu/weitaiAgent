# 标书提示词维护

本目录的 `.md` 文件只存放发送给模型的提示词正文。不要增加 Markdown 包装、标题、
代码围栏或首尾空行；它们会改变模型收到的文本。请使用 UTF-8 保存。

业务代码统一调用 `get_prompt("文件名，不带.md")`。动态 user 消息仍由业务代码组装。
`tech_plan_system.md` 中仅有 `$route_label`、`$route_topics` 两个动态变量；替换使用
`string.Template`，JSON 的 `{}` 无须转义。需要字面美元符号时写 `$$`。

模板按文件名在进程内缓存，变量值在每次调用时单独替换。修改文件后重启后端生效；
测试或维护脚本可调用 `clear_prompt_cache()`。业务模块保留的提示词常量也在导入时加载，
因此清空缓存不会更新已导入模块的常量。缺文件、空文件、缺少变量都会明确报错。

本次迁移包括识别与重试、商务起草与统稿、技术方案与单章起草、清单与图纸说明、
质检、资料字段和业绩抽取。采购类型名称和主题属于路由配置，仍在业务模块维护。
